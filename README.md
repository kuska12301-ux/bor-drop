# BOR DROP — Node.js

Самостоятельная Node.js-версия текущего интерфейса. Внешние зависимости не нужны.

## Запуск

Нужен Node.js 22.9+ (рекомендуется 24 LTS).

1. Распакуйте архив.
2. Откройте терминал в каталоге, содержащем package.json.
3. Выполните npm start.
4. Откройте http://127.0.0.1:3000.

Необязательно: скопируйте .env.example в .env для изменения порта и адреса.
Для остановки нажмите Ctrl+C.

## Что включено

Главная, три демонстрационных игровых режима на одной тестовой механике,
бонусы, промокод BOR100, задания, история, профиль, переключение темы,
демонстрационные страницы друзей и NFT-витрины.
GET /health — состояние сервера.

## FK Pay — подготовленная интеграция

Сервер содержит создание USDT-счёта, проверку статуса, HMAC-проверку webhook,
автовыплату через `FKPay.createPayout()`, защиту от повторных операций и
проверку Telegram Mini App initData. Получатель выплаты берётся только из
подписанного Telegram `@username`; клиент не может подменить его.

Для включения заполните `.env`:

- `FK_PAY_BASE_URL` — API origin из кабинета FK Pay;
- `FK_PAY_API_KEY` — ключ приложения FK Pay;
- `FK_WEBHOOK_SECRET` — секрет webhook;
- `TELEGRAM_BOT_TOKEN` — токен именно того бота, который открывает Mini App.

Webhook: `https://ВАШ-ДОМЕН/api/fk/webhook`. Нужен публичный HTTPS.
Ключи нельзя помещать в `public/`, Git или переписку.

## Ограничения

Это прототип, а не готовая к публичному запуску денежная система.
Платёжный баланс хранится на сервере, но игровая механика и её тестовые данные пока остаются в localStorage.
Для нескольких процессов или серверов JSON-журнал нужно заменить транзакционной базой данных.
Без четырёх серверных переменных платёжные API-запросы возвращают PAYMENTS_NOT_CONFIGURED.
Автовывод резервирует сумму до обращения к FK Pay и возвращает её на баланс при ошибке API.
USD в интерфейсе — обозначение тестовых единиц, не реальные доллары и не USDT.
Для Telegram Mini App нужен публичный HTTPS-хостинг; локальный адрес для этого не подходит.

## Почему Crypto Bot не подключён

Crypto Pay Policy, пункт 8.1, включает gambling среди запрещённых категорий.
Поэтому нельзя представлять этот архив как готовую реальную интеграцию Crypto Bot
для ставок. Снятие пометки demo не создаёт платёжную инфраструктуру.

Источник: https://help.cr.bot/en/articles/12594929-crypto-pay-policy
Документация API: https://help.send.tg/en/articles/10279948-crypto-pay-api

Для боевой денежной версии отдельно нужны допустимый платёжный провайдер,
проверка правовых требований, серверный журнал средств и операций,
проверка Telegram initData, идемпотентные платежи, очередь выплат,
проверяемые раунды и ограничения доступа. Секреты нельзя помещать в public/.
